## 已知限制 (Mock 模式)
1. 预测值基于成分加权公式，非真实 ML 模型
2. 一键验证仅展示流程，不实际提交仿真
3. 自动归档 Pipeline 需要集成到求解器回调中才能自动触发
4. NWB 格式导出未实现 (仅 JSON/CSV)

## 后续接入真实 ONNX 模型的步骤
1. 在 `Cargo.toml` 中添加 `ort = "1.4"` 依赖
2. 下载 CHGNet/M3GNet ONNX 模型权重到 `models/` 目录
3. 替换 `mock_predict()` 为实际 ONNX Runtime 推理
4. 将 `is_mock` 标记改为 `false`
5. 运行真实精度评测验证误差 < 15%
